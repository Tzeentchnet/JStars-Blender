# What uses Blender 5.2 and NumPy

- **Direct texture import**: DXT1/DXT5 data is wrapped in a DDS header in memory and packed straight into the Image datablock, so Blender's own decoder handles it, mipmaps included. No temp files are written. A NumPy decoder (vectorised BC1/BC3, Morton unswizzle) is the fallback and the alternative mode.
- **Bulk mesh building**: vertices, loops, UVs, colours and custom normals are transferred with `foreach_set` from NumPy arrays. Triangle strips with primitive restart are converted to triangles in vectorised NumPy.
- **Animation**: quaternion decompression, rest-pose conversion and hemisphere fixing are vectorised. Keys go into the 5.x layered Action (slots) through `fcurve_ensure_for_datablock` with bulk `foreach_set`.
- **Stage layout**: each stage collection holds the root empty and one child collection per kind: *Terrain*, *Sky*, *Props*, *Water*, *Breakable Debris* and any special categories turned on. Each placed prop is an empty named after its locator (e.g. `ya_574_5940`) with its parts as child meshes. The parts are linked duplicates that share mesh data, so they stay light, and each part can be selected and shows its materials in the outliner. *Instance Repeated Stage Props* switches back to collection instances. Each placement's damaged and destroyed states go to *Breakable Debris › Broken States*.
- **Stage water** (Planet Namek, Penguin Village) is rebuilt as a plane at the height and colour from the stage parameters, with the game's wave normal map. The game generates this plane at run time; the tiling of the wave map is an estimate. *Stage Water* in the import options turns it off.
- **Stage materials are rebuilt from the game's compiled shaders.** Each stage material has its own RSX pixel program, which blends its texture layers using splat textures, vertex-colour weights, tint constants and a slope term. The importer runs that program symbolically and turns its light-independent part into Blender nodes (Mix / Math nodes, the vertex-colour weights, a tangent-space normal), so terrain shows the right layers instead of a splat map. *Rebuild Stage Shaders* in the preferences switches back to plain slot wiring.
